# Components

The SolidJS layer the `kai-*` web components compose from. Every component, with controls and source. The full element API and framework usage are at [ui.kitn.ai](https://ui.kitn.ai).

## One tier

Everything under `Components` is a Solid component, from the accessible building blocks (`Button`, `Tooltip`, `Dropdown`, `Switch`, …) to the chat surface (`Message`, `Tool`, `Reasoning`, `Composer`, `Artifact`, …). No third-party UI deps. Which of them have a `kai-*` element is a documented fact per component, not a separate tier here.

The `kai-*` elements themselves, and the compositions built from them, are in **Labs**.

## Each story

- **Demo**: the live component, with controls.
- **Actions**: events stream here as you interact.
- **Code**: the story's SolidJS source.

Theme everything with the design tokens in [Token Reference](?path=/docs/getting-started-token-reference--token-reference).
