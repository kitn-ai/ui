<Aside type="tip" title="When to use">
Any user-triggered action: submitting input, a toolbar action, confirming, dismissing. `default` is the primary action, `subtle` / `ghost` / `outline` the low-emphasis ones.
</Aside>

## Usage

Put the label as light-DOM text inside the element. Set `variant` and `size`, add `icon` for a leading glyph, and listen for `kai-click`. For an icon-only button, drop the text, set `size="icon"`, and name it with `label`.

```html
<kai-button variant="subtle" size="icon" icon="mic" label="Voice input"></kai-button>
<kai-button variant="ghost" icon-trailing="chevron-down">High</kai-button>
<kai-button>Send</kai-button>
```

### Icon-only

Square sizes are `icon` / `icon-sm`; set `label` for the accessible name. `icon` takes a named icon, an image URL, or a data-URI.

<Example client:visible tag="kai-button" config={{ variant: 'subtle', size: 'icon', icon: 'mic', label: 'Voice input' }} data="iconOnly" />

### Trailing icon

`icon-trailing` sits after the label.

<Example client:visible tag="kai-button" config={{ variant: 'ghost', iconTrailing: 'chevron-down' }} data="model" />

### Custom icon via slot

For a glyph the `icon` prop can't name, slot it into `slot="icon"`; it wins over the prop. Keep `label` for the accessible name.

<Example client:visible tag="kai-button" config={{ label: 'Ship' }} data="slottedIcon" />

## Slots

The label is the default slot; `icon` is the one named seam:

<SlotTable tag="kai-button" />

```html
<kai-button label="Ship">
  <svg slot="icon" viewBox="0 0 24 24" width="16" height="16"><!-- your glyph --></svg>
  Ship it
</kai-button>
```

## Styling

The button is a single `::part`, so radius, padding, color, and weight restyle from outside while `variant` / `size` stay the defaults.
