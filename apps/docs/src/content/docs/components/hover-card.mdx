## Preview

<Aside type="tip" title="When to use">
When the preview is *content*: an avatar that opens a profile, a mention that shows who someone is. For a plain-text hint on an icon button, use [Tooltip](/components/tooltip/) instead.
</Aside>

## Usage

Put the trigger in the default slot and the panel in `slot="card"`. The card is portaled and positioned inside the shadow root, with a transparent bridge so the pointer can travel in without closing it. It opens on hover and on keyboard focus.

`openDelay` (default `0`) and `closeDelay` (default `300` ms) tune the timing, and `placement` steers the panel, which flips to stay in view.

```html
<kai-hover-card placement="top">
  <a href="#">@acme</a>
  <div slot="card">
    <strong>Acme Corp</strong>
    <p>Workspace · 24 members</p>
  </div>
</kai-hover-card>
```

## Slots

The trigger is the default slot; the card is the one named seam:

<SlotTable tag="kai-hover-card" />

```html
<kai-hover-card>
  <kai-avatar src="/jordan.jpg" alt="Jordan Lee"></kai-avatar>
  <div slot="card">
    <strong>Jordan Lee</strong>
    <p>Staff engineer · Platform</p>
  </div>
</kai-hover-card>
```
