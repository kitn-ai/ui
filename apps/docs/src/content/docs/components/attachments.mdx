## Preview

<Playground client:only="solid" tag="kai-attachments" />

<Aside type="tip" title="When to use">
Show the files a prompt carries or a message cites: the composer, a message body, a sources rail. For a cited link rather than a file, use [Link preview](/components/link-preview/).
</Aside>

## Usage

Set `items` in JavaScript (arrays can't be HTML attributes); choose the presentation with the `variant`, `hover-card`, and `removable` attributes; listen for `kai-remove`.

## Examples

### Grid

`variant="grid"` — square image tiles for a gallery.

<Example client:visible tag="kai-attachments" config={{ variant: 'grid' }} data="images" />

### Inline

`variant="inline"` — a compact icon + label chip per file, for a composer or message body.

<Example client:visible tag="kai-attachments" config={{ variant: 'inline' }} />

### List

`variant="list"` — full-width rows with a preview thumbnail, filename and media type.

<Example client:visible tag="kai-attachments" config={{ variant: 'list' }} />

### Removable

Add `removable` for a per-item remove button (the **×**); it fires the `kai-remove` event.

<Example client:visible tag="kai-attachments" config={{ variant: 'list', removable: true }} />

### Hover preview

Add `hover-card` to reveal each item's details on hover — useful on `grid`, where the tile shows only the image.

<Example client:visible tag="kai-attachments" config={{ variant: 'grid', hoverCard: true }} data="images" />

### Lightbox

For a gallery where the point is looking at the picture, `image-preview="lightbox"` trades the hover card for a modal: click an image tile and it opens full-size, with Escape, a backdrop click or the close control to dismiss it. It applies to image items only; every other item keeps the hover card, so one container can serve a mixed set.

<Example client:visible tag="kai-attachments" config={{ variant: 'grid', imagePreview: 'lightbox' }} data="images" />

The modal is the kit's own [Lightbox](/components/lightbox/), which composes the kit's Dialog: it portals through the host's mount point, moves focus into the panel and restores it on close, traps Tab, and carries `role="dialog" aria-modal`. Nothing about it is a second modal implementation, so an attachment lightbox behaves like every other dialog in the kit for keyboard and screen-reader users.

Composing your own tile? The trio is public in the Solid entry:

```tsx
<Lightbox>
  <LightboxTrigger>
    <AttachmentPreview />
  </LightboxTrigger>
  <LightboxContent label="Screenshot">
    <img src={url} alt="" class="block" />
  </LightboxContent>
</Lightbox>
```
