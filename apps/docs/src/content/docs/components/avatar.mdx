Anywhere you need a small identity mark outside a thread: a conversation list, a composer byline. Inside a thread, [Message](/components/message/) already has an `avatar` slot.
</Aside>

## Usage

Set `src` to an image URL or data-URI and `fallback` to a short initials string. When `src` is absent, or the image fails to load, the initials render instead, so the badge is never empty. `alt` describes the image (it defaults to `fallback`), and every prop is a plain scalar attribute with no slotted content.

```html
<kai-avatar src="/me.jpg" alt="John Doe" fallback="JD"></kai-avatar>
<kai-avatar fallback="AI" size="sm"></kai-avatar>
```
