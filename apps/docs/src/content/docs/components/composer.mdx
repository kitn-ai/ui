<Aside type="tip" title="Composer or Prompt Input?">
The bare editing surface: no send button, suggestions, or attachments. Use it where you need a rich pill input that *isn't* a chat composer, such as an inline comment box or a `@`-reference search field. For a drop-in chat composer, use [`<kai-prompt-input>`](/components/prompt-input/), which is built on this.
</Aside>

## Usage

Register web components once, then set the trigger definitions as a JS property and listen for events:

```html
<kai-composer id="composer" style="display:block; width:100%;"></kai-composer>

<script type="module">
  import '@kitn.ai/ui/web-components';

  await customElements.whenDefined('kai-composer');
  const composer = document.getElementById('composer');

  // `/` inserts skills; `@` opens a sectioned menu of agents + plugins.
  composer.triggers = [
    { char: '/', kind: 'skill', items: [
      { id: 'summarize', label: 'Summarize', description: 'Summarize the thread' },
    ]},
    { char: '@', kind: 'agent', items: [
      { id: 'code-reviewer', label: 'Code Reviewer', group: 'Agents' },
      { id: 'documents', label: 'Documents', kind: 'plugin', group: 'Plugins' },
    ]},
  ];

  composer.addEventListener('kai-submit', (e) => {
    // e.detail = { doc, text, entities } — references, not resolved content.
    console.log(e.detail.text, e.detail.entities);
  });
</script>
```

- **Set objects as properties**: `triggers`, `highlights`, `kindIcons`, and a document `value` are arrays/objects, so assign them in JavaScript. Scalars (`placeholder`, `disabled`, `loading`, `maxHeight`, `submitOnEnter`) work as attributes.
- **The document is the source of truth.** Each pill is an `EntityRef` (`{ kind, id, label, icon?, promptText?, data? }`) and the composer emits *references*, never resolved content; your backend expands `/summarize` or `@code-reviewer` before the model call.
- **`text` is a default flatten**: each entity becomes its `promptText ?? label`. Pass your own serializer for a different wire format.
- **Per-kind decoration.** Skills and agents render as sigil-led text (`/summarize`, `@code-reviewer`); plugins render as a richer chip, since a plugin bundles tools, skills, and agents. Recolor with `--kai-pill-skill` / `--kai-pill-agent`.
