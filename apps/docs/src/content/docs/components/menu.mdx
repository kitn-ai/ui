## Usage

Build the menu from its `items` tree, set in JavaScript because arrays can't be HTML attributes. Each item is an action (`id` + `label`, optional `icon`/`shortcut`), a `heading`, a `separator`, a checkbox (add `checked`), or a submenu (nest more `items`). Selecting a leaf fires `kai-select` with its `id`.

The trigger is the built-in button (`trigger-icon` / `trigger-label`), or your own element in `slot="trigger"`.

```html
<kai-menu trigger-icon="plus" label="Add content"></kai-menu>

<script type="module">
  import '@kitn.ai/ui/web-components';

  const menu = document.querySelector('kai-menu');
  menu.items = [
    { heading: true, label: 'Actions' },
    { id: 'add-files', label: 'Add files or photos', icon: 'paperclip', shortcut: '⌘U' },
    { id: 'add-github', label: 'Add from GitHub', icon: 'github' },
    { separator: true },
    { id: 'web-search', label: 'Web search', icon: 'globe', checked: true },
  ];

  menu.addEventListener('kai-select', (e) => {
    console.log(e.detail); // { id } — or { id, checked } for a checkbox item
  });
</script>
```

## Slots

The menu builds its own trigger from the `trigger-*` props; slot your own element for full control of it:

<SlotTable tag="kai-menu" />

```html
<kai-menu>
  <button slot="trigger" aria-label="Open menu">+</button>
</kai-menu>
```
