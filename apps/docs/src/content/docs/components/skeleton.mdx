<Aside type="tip" title="When to use">
When you know the shape of what's loading and want to reserve its space: an avatar, a few lines of copy, a card. For a busy indicator with no shape, use [Loader](/components/loader/) instead.
</Aside>

## Usage

Set `variant` to `text`, `rect`, or `circle`. Width fills its container by default; pass `width` / `height` to pin a size. `lines` stacks rows for `text` and shortens the last one.

```html
<kai-skeleton variant="text" lines="3"></kai-skeleton>
<kai-skeleton variant="circle" width="2.5rem"></kai-skeleton>
<kai-skeleton variant="rect" height="10rem"></kai-skeleton>
```

The shimmer is a low-contrast foreground tint, so it reads in both light and dark; recolor it or change its opacity via `::part(skeleton)`.
