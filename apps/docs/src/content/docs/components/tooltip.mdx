## Preview

<Playground client:only="solid" tag="kai-tooltip" />

<Aside type="tip" title="When to use">
Label a control whose purpose isn't obvious from its face — an icon-only button, a terse menu item, a status dot. The hint shows on hover and on keyboard focus, so it stays accessible. The tip is text by default; a `content` slot child adds markup (a key cap, an icon, a short label), which is enough for a shortcut hint. For a whole panel of rich content (a heading, a thumbnail, links) reach for [Hover Card](/components/hover-card/) instead.
</Aside>

## Usage

Put the trigger in the default slot — any focusable control — and set `content` to the hint text. The tooltip positions itself next to the trigger, portals its bubble inside the shadow root so it isn't clipped, and dismisses on Escape or an outside click. Tune the hover delay with `openDelay` (focus always shows it immediately).

```html
<kai-tooltip content="Voice input">
  <kai-button variant="subtle" size="icon" icon="mic" label="Voice input"></kai-button>
</kai-tooltip>
```

### A snappier delay

`openDelay` sets the hover wait in milliseconds (default 600). Drop it for hints you want to surface faster.

<Example client:visible tag="kai-tooltip" config={{ content: 'Voice input', openDelay: 150 }} />

### Markup in the tip

A child carrying `slot="content"` replaces the `content` text, so a tip can hold a key cap, an icon, or a label with a shortcut in it. The bubble is an inverted surface: it re-expresses the muted, border and foreground tokens on itself, so a kit component inside it adapts instead of reading as a light blob on a dark bubble.

<div class="not-content my-4 flex flex-wrap items-center gap-4 rounded-xl border border-line bg-surface px-5 py-4">
  <kai-tooltip default-open>
    <kai-button variant="outline">Save</kai-button>
    <span slot="content">Save changes <kai-kbd keys="Mod+S"></kai-kbd></span>
  </kai-tooltip>
</div>

```html
<kai-tooltip>
  <kai-button variant="outline">Save</kai-button>
  <span slot="content">Save changes <kai-kbd keys="Mod+S"></kai-kbd></span>
</kai-tooltip>
```

Anything a light-DOM child can hold works here, because the bubble is portaled inside the element's own shadow root: the slotted content sits next to the kit's stylesheet and tokens. Set `content` as well to keep a text fallback for the same tip.
