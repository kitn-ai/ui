Any region that overflows its space: a long thread, a settings panel. For a chat transcript that auto-sticks to the latest message, reach for [Conversations](/components/conversations/) instead.

## Usage

Put the content as light-DOM children, which land in the default slot, and give the element a bounded height in your own layout. Past that height the content scrolls inside, and the thin scrollbar follows the `--color-scrollbar-thumb` token. The inner padding or max-height restyles from outside via `::part(viewport)`.

```html
<kai-scroll-area style="height: 16rem">
  <p>…long content that overflows the height…</p>
  <p>…more content…</p>
</kai-scroll-area>
```
