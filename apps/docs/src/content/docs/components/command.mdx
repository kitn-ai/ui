<Aside type="tip" title="When to use">
When the user has to pick one thing out of many, fast: an @-mention picker, a slash-command menu, a model switcher. For a static action list, a plain [Menu](/components/menu/) is lighter.
</Aside>

## Usage

Set `items` as a JS property: a flat array, never an attribute. Each item needs an `id` (echoed back in `kai-select`) and a `label`; add `group` to bucket it under a header, plus `icon` and `description`. Listen for `kai-select` for the picked `id`, and `kai-query-change` to drive your own async filtering.

```html
<kai-command placeholder="Search files, chats, people…"></kai-command>
<script type="module">
  import '@kitn.ai/ui/web-components';
  const el = document.querySelector('kai-command');
  // Array prop — set in JS, never as an HTML attribute.
  el.items = [
    { id: 'screen9', label: 'screen9.py', icon: 'file-text', description: '/Users/rob/screen9.py', group: 'Files' },
    { id: 'rs', label: 'Record screen', icon: 'message-circle', group: 'Chats' },
  ];
  el.addEventListener('kai-select', (e) => console.log('picked', e.detail.id));
  el.addEventListener('kai-query-change', (e) => console.log('query', e.detail.value));
</script>
```
