## Preview

<Playground client:only="solid" tag="kai-embed" />

<Aside type="tip" title="When to use">
When a response references a video and you want it inline without silently loading third-party scripts. YouTube and Vimeo work as-is; `generic` needs an allowlisted origin.
</Aside>

## Usage

Set `data` in JavaScript (it's an object, not an attribute) on the element:

```html
<kai-embed id="em"></kai-embed>
<script type="module">
  import '@kitn.ai/ui/web-components';

  await customElements.whenDefined('kai-embed');

  const em = document.getElementById('em');
  em.data = { provider: 'youtube', id: 'dQw4w9WgXcQ', title: 'Product intro' };
</script>
```

- **`provider`**: required; `'youtube'`, `'vimeo'`, or `'generic'`. YouTube uses `youtube-nocookie.com` and Vimeo appends `dnt=1`; neither loads provider JS until play.
- **`generic` embeds are blocked by default**: call `configureEmbedAllowlist(['https://your-player.example.com'])` before setting data, or the origin is rejected.
- **Vimeo** has no static thumbnail URL — supply a `poster` URL or the facade renders without an image.
- **"Open on provider"** is always visible; on click it fires `kai-card` with `{ kind: 'open', target: 'tab' }` — handle it to open the URL yourself.
