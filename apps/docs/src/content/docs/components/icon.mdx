<Aside type="tip" title="When to use">
When you need one of the kit's glyphs in your own markup: a heading, a stat tile, a custom button. For a glyph outside the curated set, drop your own inline `<svg slot="icon">`.
</Aside>

## All icons

Deliberately small: the glyphs the kit's own web components use. Pick one by `name`:

<IconGallery />

## Usage

Set `name` and a `size` of `sm` / `md` / `lg`. An unknown name renders as literal text, plus a dev-time warning.

```html
<kai-icon name="globe"></kai-icon>
<kai-icon name="sparkles" size="lg"></kai-icon>
```

### Recolor with ::part(icon)

The glyph inherits `currentColor`, so recolor it from outside through the `icon` part.

```css
kai-icon::part(icon) { color: var(--color-primary); }
```
