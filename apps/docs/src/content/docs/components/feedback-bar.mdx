<Aside type="tip" title="When to use">
At the end of an assistant response, a completed task, or an article. Add `collect-detail` for an optional reason on a thumbs-down; the element runs the flow, and you listen for `kai-feedback-detail`.
</Aside>

## Usage

Drop `<kai-feedback-bar>` after any response. It transitions to a thank-you on vote; the × button fires `kai-close` and you decide when it leaves the DOM.

- **Copy**: override any label with attributes: `bar-title`, `detail-title`, `detail-placeholder`, `submit-label`, `thanks-message`.
- **Detail form**: `collect-detail` opens a follow-up form on a thumbs-down vote. Set `categories` in JavaScript (it's an array) to render selectable chips.
